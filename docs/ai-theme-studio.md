# AI 主题创作 · 3.2

在外观工作室的“一起设计你的主题”中输入意向或多句要求，添加参考图，然后点击“生成预览”。AI 会在关键信息缺失时追问并给出推荐；普通构图细节由 AI 根据内置规则决定。继续反馈，满意后点击“保存并应用”；也可以先临时试用 20 秒，自动恢复。

3.2.1 修复：作品作为界面下方的背景合成，取消逐字/逐段挖洞。更新后现有作品的异常色块和滚动闪烁会修复，但原有图案不会自动重画；可在原版本上继续反馈或导入新的草稿。

## 能做什么

AI 可以组合路径、几何、渐变、连续噪声、重复图形、混合与时间表达式，创作图案、自然轮廓、光带和动态纹理，同时设计配色、字体参数、材质与交互状态。意向不局限于粒子预设。规则要求覆盖意向、构图、颜色与阅读、图案与素材、材质与光照、动态与状态、适配与交付七项职责。

默认在当前草稿上局部修改；“重新设计整套主题”从默认外观开始并保留已选择的壁纸。作品画布显示独立作品，旁边的内容预览显示固定界面样例。“临时试用”才能查看当前宿主的实际保护区。装饰不改变界面结构，也不能访问文件、DOM 或网络。

当前后端是受限制的 Canvas2D 绘制语言，不执行生成的 JavaScript 或任意 CSS。它不提供真实背景折射、像素采样、任意布局或图像生成服务。毛玻璃由已有材质参数实现；程序图层的混合并不等于真实玻璃折射。

## 图片与素材

- “添加参考图”默认只用于理解外观。最多三张，每张不超过 2 MB，支持 PNG、JPEG、WebP、GIF。提交时发送列出的参考图。
- 只有明确勾选“允许作为作品素材使用”，AI 才能把该图片嵌入作品；嵌入限 PNG、JPEG、WebP。分享时需有相应图片权利。
- “选择实际壁纸”只在本机保存并加入草稿，不会自动发送给模型。
- 需要现成图片时，AI 可搜索 Wikimedia Commons。仅接收搜索结果中的官方图片地址和可识别的 CC0、公有领域、CC BY/CC BY-SA 许可，保留来源、作者与许可；下载失败或无合格结果时可改用原创绘制。
- 素材经过哈希和解码检查，在本机 IndexedDB 中去重保存。单图最多 1600 万像素，整幅作品最多 2400 万像素；仅实际引用的素材进入完整风格包。

默认使用 DSH 默认模型，也可指定设计模型。设计模型不支持图片时，会使用已配置的视觉模型协作描述参考图。有可用视觉模型和附件服务时，也会检查实际渲染截图；否则明确标为人工审阅。插件不保存 API Key，所有模型请求沿用宿主凭据，设计和视觉协作都会消耗对应模型用量。

## 检查与恢复

每个候选版本实际捕获四组画面：桌面阅读、桌面菜单、移动文档与减少动态模式；包含不同动画相位。检查绘制文档、资源、派生配色对比度、阅读面边界、帧耗时、配置与素材往返。空白截图不能进入视觉验收。每个用户请求最多三轮自动修正，失败保留此前草稿。浏览器还测量各层在最终画面中的颜色影响，数值区分静态、平移、形变/旋转和明暗变化。没有视觉模型时，会额外调用设计模型审查程序与意向是否一致；它不等于实际看图，相关未知项仍交给人工审阅。

这些检查覆盖独立作品画布与固定阅读样例，并不代表所有真实宿主页面、整段动画或所有设备均已验收。宿主运行时使用同一解释器，以正常界面层级保护文字与控件、隐藏时暂停、减少动态或省电时静态显示，持续超出帧预算时静态降级。视觉检查不能绕过技术失败，最终审美由用户决定。

本地会话保留对话、输入、参考图与草稿历史，重开可恢复；回退后继续设计会保留原有分支。取消、关闭或修改基准后，迟到结果不能覆盖新草稿。删除会话会清理独占且未保存主题使用的壁纸和绘制素材。宿主附件服务及模型提供方可能另存图片，本地删除不删除这些副本。

完整风格包 v2 内嵌程序与使用到的素材，可独立导入恢复，兼容旧 v1。参考图、对话与无关个人设置不进入风格包。其他应用的配色格式不能携带绘制层，请使用“导出完整风格包”。

## 接口与开发验证

复用 Connection 的认证 `/api/desktop-themes-ai/` 路由：`models`、`create`、`inspect`、`cancel`；保留 `generate` 配色兼容入口。旧宿主回退原 RPC 通道。请求可取消，单次服务等待上限三分钟；待验收任务三十分钟过期。

```sh
npm run typecheck
npm test
npm run audit
npm run build
npm run test:ai-studio-browser
npm run test:creator-browser
npm run test:artwork-scroll
npm run test:studio-browser
node scripts/verify-desktop-ai.mjs "D:/deepseek/DeepSeek Harness.exe"
```

测试使用固定模型响应，验证真实浏览器绘制与 Electron 接口，不调用付费模型。不同提供方的实际创作质量仍需使用者测试并反馈。

# AI 主题设计助手

在外观工作室的预览下方找到“一起设计你的主题”。输入多句要求后点击“生成预览”，通过校验的结果会更新主题草稿。继续描述需要调整的地方，满意后点击工作室顶部“保存并应用”，也可以先在宿主中临时试用 20 秒。

默认以当前草稿为基础，只修改本轮要求涉及的字段。勾选“重新设计整套主题”会从默认外观参数开始设计，并保留已选择的实际壁纸。AI 只能调整现有主题字段；不支持任意界面布局、代码、截图逐像素还原或生成新壁纸。

## 图片与模型

- “添加参考图”用于理解颜色、材质和风格；提交时会发送界面中列出的全部参考图。最多三张，每张不超过 2 MB，支持 PNG、JPEG、WebP、GIF。
- “选择实际壁纸”将图片保存到本机并加入草稿，不会自动发送给模型。
- 默认使用 DSH 的宿主默认模型，不跟随某个聊天会话单独切换的模型。“设计模型”可为本次设计选择其他已注册模型，不会修改宿主默认值。
- 图片设计只启用已在模型目录中声明图片输入能力的模型；能力未知时也会提示选择支持看图的模型。
- 插件不接收或保存 API Key。模型请求由宿主管理，沿用宿主的提供方与凭据设置。

## 多轮调整与恢复

设计版本会保留所有成功生成的草稿。选择任意旧版本后可以继续修改，此前的后续版本仍然保留。对话、输入、参考图、工作中的草稿及版本保存在浏览器的本地 IndexedDB，刷新或重新进入工作室会自动恢复。首版保留一份正在进行的设计会话。

删除设计会话会清除本地对话、参考图、历史草稿，以及该会话独占且未保存应用的壁纸。当前正式主题仍使用的壁纸会保留。发送过的参考图还可能由 DSH 附件服务及模型提供方保存；插件的本地删除操作不删除这些副本，宿主附件服务目前没有删除接口。

草稿修改、回退或关闭工作室会取消正在进行的旧请求；即使结果迟到，也不能覆盖新草稿。格式错误、越界字段或可读性不合格时，会尝试修复一次；仍失败则保留原草稿。网络错误和取消同样保留原草稿。请求最长等待三分钟。

保存后的主题继续使用现有风格包导出和导入流程，对话及参考图不进入风格包。

## 宿主要求与验证

AI 功能需要宿主启用 `connection.rpc`、`llm`、`agentDefaultModel`，图片请求还需要 `attachments` 以及支持图片输入的提供方模型。缺少服务时，工作室原有主题编辑功能仍可使用；AI 调用会显示连接或模型错误。

现代宿主使用 `/api/desktop-themes-ai/models` 和 `/api/desktop-themes-ai/generate` 两个认证接口，沿用 Connection 的来源检查、owner 权限与请求取消机制。旧版宿主回退到 `/desktop-themes-ai` 通道。此通道仅用于工作室，不向模型注册可调用的工具。

开发验证：

```sh
npm run typecheck
npm test
npm run build
npm run test:ai-studio-browser
npm run test:studio-browser
```

自动化覆盖宿主与客户端接口、输出校验及浏览器完整交互。模型测试使用固定响应，不调用付费服务。真实 Electron 宿主中的模型效果、提供方凭据与所有页面的实际外观仍需运行验证；工作室使用固定示例预览。

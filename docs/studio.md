# 外观工作室 · 2.1

在 DSH 左侧栏点击「外观工作室」，或在「桌面外观」设置顶部点击同名入口。

## 调色与保存

左边选择起点，中间查看示例会话、代码、diff、输入框与 ANSI 色板，右边编辑七个语义颜色。画布使用示例内容，不读取真实会话。所有编辑均为内存草稿，离开工作室后未保存的草稿丢弃。

OKLCH 滑杆调整感知亮度、彩度、色相；超出 sRGB 时降低彩度以保留色相。支持 20 步撤销/重做、七色协调、A/B 基线对比。Ctrl/Cmd+Z 撤销，Shift+Ctrl/Cmd+Z 重做；文字框保留系统自己的撤销行为。

「保存并应用」更新当前自定义主题，内置主题会保存成新主题；「另存为新主题」总是创建新主题。可读性不合格时禁止保存，检查器列出具体色对。修复按钮调整正文与强调色；极端背景/面板组合可能仍需要手工调整。最多保存 50 套自定义主题。

字体、壁纸、伙伴和粒子参数不因调色保存被覆盖。左栏「应用完整场景」会直接应用场景配方。

## 格式互通

| 格式 | 支持范围 |
| --- | --- |
| VS Code | JSON/JSONC；编辑器、侧栏、按钮、focus/link；常用 TextMate scope 与 16 ANSI 色 |
| Base16 / Base24 | JSON 与普通键值 YAML，支持 `palette` 嵌套；保留语义映射与 ANSI 色 |
| iTerm | XML `.itermcolors` 中的 RGB 数字字典；不支持二进制 plist |
| shadcn / Tweakcn | 选择 `:root` 或 `.dark`；HEX、OKLCH、HSL 色值；不解析变量引用、透明色、任意 CSS 表达式 |
| DSH | 原生单主题 JSON，保留七色、语法、ANSI、家族和变体元数据 |

文件限 1 MB；既可选择文件，也可粘贴内容。导入只修改草稿，不自动保存。覆盖率明确指七个核心语义色的映射比例，不代表整个 VS Code token 集合的兼容率。缺失项使用内置主题回退；不访问 `include`、URL 或外部文件。

代码语法色在应用时保证对实际代码底色至少 4.5:1。ANSI 颜色保留用于预览与导出；宿主终端联动属于 2.2。跨格式转换保留对应的语义意图，不保证逐 token 无损转换；原生 DSH 格式用于完整单主题备份。

## 主题家族与昼夜

可生成浅色、深色、高对比、蓝橙、OLED、纸感变体。变体保留家族标识；分别保存浅色与深色版后，可在左栏「自动昼夜」选择家族并启用。

时间使用设备本地时区：07:00–19:00 为浅色，其他时间为深色；每分钟及窗口可见性变化时检查。默认关闭，不查询位置。手动换主题、应用场景或保存主题会暂停自动切换。

蓝橙变体减少红绿依赖，但未经过色觉认证。工作室目前为中文界面。

## 验证与基线

`npm test`、`npm run typecheck`、`npm run audit`、`npm run test:studio-browser`。

浏览器脚本使用现有 Codex runtime 中的 Playwright/pngjs/pixelmatch 和本机 Edge，无需安装新依赖。12 张基线覆盖六套主题 × 1280×800 / 1920×1080，位于 `tests/visual/studio/`。包括工作室及其会话示例，不代表宿主所有设置页/会话页均已完成回归。

截图比较阈值为像素差异比例 0.1%；字体或浏览器版本变化可能需要人工检查。先检查 `docs/screenshots/studio/`，再设置 `DTH_UPDATE_VISUAL=1` 运行脚本更新基线。差异图输出到 `tmp/studio-preview/`。当前基线由 Windows/Edge 生成，应在相同平台上比较。

10 个真实社区主题样本位于 `tests/fixtures/themes/`，来源及原作者在文件中保留。

`.github/workflows/quality.yml` 配置单测/类型/门禁/构建 CI，并提供手动触发的 Windows 自托管视觉任务。后者需要匹配字体与 Edge 的 runner，以及 Codex runtime（可用 `DTH_RUNTIME_NODE_MODULES` 指定依赖目录）。本次仅执行了本地验证，未触发远程 CI。

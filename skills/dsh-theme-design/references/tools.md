# 工具契约

这是主题创作协议 v1 的规范。工具必须在运行时能力清单中公布后才能调用。当前 3.1.x 的配色生成接口不是这里全部工具的实现。

## 公共请求与回执

每个请求携带 `requestId`、`sessionId`、`baseVersion`、`capabilityRevision`；会改变草稿的请求另外携带 `draftRevision`。运行时校验版本并支持取消。结果携带相同关联标识、执行状态、结构化问题与运行时签发的 `receiptId`。旧版本的迟到结果不能修改当前草稿。

问题至少包含 `code`、`path`、具体原因、是否可自动修复及恢复方式。缺少能力返回 `capability-unavailable`；等待用户信息返回 `needs-input`；预算耗尽返回 `budget-exceeded`。任何状态均不代表已经保存应用。

工具回执由运行时登记，模型只能引用。回执绑定设计内容摘要、基准版本与能力版本；修改后原证据失效。模型自己填写的检查结论不构成工具证据。

运行时为每次完整验收指定 `inspectionId`，门禁读取当前有效批次内的全部报告；模型不能只选通过的回执来遗漏失败。重新验收由运行时建立新批次，完成必要检查后取代旧批次，保留历史证据。批次变更和检查取代不由模型提交的字段决定。

## 操作

| 操作 | 前提与输入 | 必须返回 | 失败或缺少能力 |
|---|---|---|---|
| `theme.capabilities.read` | 会话与基准版本 | 实际工具、后端/语言、可用逻辑区域、布局事实、字体、模型模态、资源/性能预算、规则版本 | 明确缺项；能力未知按不可用处理 |
| `theme.intent.clarify` | 阻碍设计的问题、影响与推荐选择 | 向用户展示的问题与已有决定；回答后返回更新的意向版本 | 等待期间不发起依赖答案的操作；不丢草稿 |
| `theme.assets.search` | 意向、素材角色、搜索预算和来源条件 | 候选原始来源、预览、尺寸、作者/提供方与使用条件证据；仅搜索不取得使用授权 | 换查询/来源或采用生成；不虚构结果 |
| `theme.assets.acquire` | 已选候选及使用条件证据；用户图片直接使用的用途授权 | 校验后的本地资源标识、哈希、格式、尺寸、来源与使用依据回执 | 拒绝来源或用途不明、格式/像素越界、不可访问资源 |
| `theme.assets.transform` | 已登记资源、用途、变换及参数 | 新资源与哈希、输入引用、变换记录；必要时返回轮廓/裁切预览 | 原资源保留；具体报告不能完成的处理 |
| `theme.assets.generate` | 已配置的图像生成提供方、本次调用授权、意向、用途、输入素材与预算 | 实际生成资源、哈希、提供方/模型与输入引用、使用条件回执 | 未配置时采用可用绘制方式或询问；不虚构图片生成 |
| `theme.program.validate` | 后端/语言、程序、资源与区域引用、预算 | 编译/静态检查结果、操作和资源用量、隔离策略、程序摘要 | 不执行未通过的程序；返回定位信息 |
| `theme.draft.stage` | 完整设计文档或有明确基准的局部修改；相关资源/程序回执 | 原子生成的新草稿版本、完整决定、实际改动、继承关系 | 校验失败不替换上一有效版本 |
| `theme.render.preview` | 草稿版本、视口/状态/相位、种子、静态模式 | 实际可见的合成画面及预览标识、布局/保护区、渲染耗时与采样元数据 | 返回明确不可渲染原因；超时取消并释放资源 |
| `theme.render.capture` | 当前实际预览回执、需要检查的视口/状态/相位 | 可供视觉模型读取的真实截图资源、哈希、预览关联与采样元数据 | 不可用时保留实时人工预览，不宣称完成自动视觉检查 |
| `theme.inspect.technical` | 当前草稿及实际渲染回执 | 结构、资源、程序、局部合成对比度、保护区、帧预算、生命周期与静态回退结果 | 未检查项保持 `unknown`；不能把未执行写成通过 |
| `theme.inspect.visual` | 用户意向、决定、真实 capture 回执与视觉模型选择 | 逐条意向证据、构图/材质/节奏问题、截图与相位引用、置信度 | 无截图或视觉模型时说明缺口，转人工预览；不声称视觉检查已通过 |
| `theme.pack.validate` | 草稿、实际资源、后端依赖及来源清单 | 独立环境导出/导入、离线恢复和资源一致性报告 | 缺失资源或未知程序版本阻止正式交付 |
| `theme.commit` | 用户确认的具体草稿版本、有效硬门禁回执 | 原子保存与应用结果；失败可恢复旧版本 | 未获确认、证据缺失或过期则拒绝 |
| `theme.pack.export` | 用户请求导出的版本、有效交付回执 | 包版本、资源清单、校验值及文件 | 不包含对话、参考图或凭据；保留原草稿 |

## 能力与执行权

搜索和图像生成是独立的可选提供方能力，不属于绘制程序的网络权限。没有已配置的工具时，AI 可提出替代方案或说明如何补足能力。

工具名不授予额外授权。素材使用授权、外部模型调用范围、用户的保留项与最终保存确认分别保留。程序校验、渲染与草稿预览可以在已授权的设计范围内自动执行。

所有持久化变更须能定位到会话、用户请求和版本。对话修正与工具内部重试不能绕过三轮自动修正预算。取消后停止新增外部调用，回滚未提交草稿并清理独占临时资源。
